# Tanmoy's Portfolio 🚀

A premium, interactive, sci-fi themed developer portfolio showcasing custom projects, engineering philosophy, and custom code integrations.

> [!NOTE]
> Designed with high-fidelity aesthetics, immersive audio routing, and real-time WebGL graphics, this portfolio serves as an interactive hub for my technical creations.

## 🌟 Key Features

- **Interactive 3D Planetary Canvas**: Powered by Three.js and custom shader materials, featuring orbital rings, atmospheric glows, and smooth mouse/touch interactivity.
- **Developer CLI Terminal**: An interactive command-line interface overlay (accessible via `` ` `` or `Ctrl+K`) that accepts developer commands and provides real-time system responses.
- **TechScript Playground**: A custom mini-IDE & syntax highlighter console to write and test code snippets directly in the browser.
- **Skill Constellation Map**: Node-based interactive tech stack constellation mapping out expertise dynamically with custom animations.
- **Dynamic Projects & Case Studies**: Immersive full-screen project previews with modern grid transitions, custom audio feedback cues, and detailed markdown support.
- **Github Activity Engine**: Dynamically displays pinned repos with a responsive swiper track on mobile and direct link interaction.
- **Ambient Sound Design**: High-fidelity sound manager with spatial hover audio cues, click triggers, and immersive background tracks.
- **Responsive Layout**: Designed for mobile compatibility (vertical stack reordering, sliding controls, custom carousels) and ultra-wide PC monitors.
- **Integrated Mail Client Routing**: Smart custom contact form with subject selectors, conditional entries, and client preferences (`localStorage`) to auto-launch Gmail Web, Outlook Web, or default native mail applications.

## 🛠️ Modern Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling & Motion**: Tailwind CSS + Framer Motion + GSAP
- **3D Graphics**: Three.js / WebGL / React Three Fiber / Drei
- **Typography & Icons**: Lucide React + custom sci-fi font tokens
- **Orchestration & Performance**: Lenis Smooth Scroll + SoundManager Audio (Howler) + Vanta.js

## 🚀 Getting Started

### Prerequisites

Make sure you have Node.js installed.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Tcode-Motion/portfolio.git
   cd portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
