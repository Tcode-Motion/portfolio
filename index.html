TechScript — Programming Language by Tanmoy Majumder

TechScript is a modern programming language created by Tanmoy Majumder and built entirely in Rust. It features a custom lexer, recursive descent AST parser, bytecode compiler, NaN-boxed stack-based virtual machine, and a Studio IDE. TechScript is designed to be readable and beginner-friendly while running on a high-performance Rust foundation.

TechScript by Tanmoy Majumder (Tcode-Motion) is open source and available at github.com/Tcode-Motion.
